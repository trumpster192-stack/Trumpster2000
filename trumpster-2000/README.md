# 🦅 TRUMPSTER 2000 - Phase 1 MVP

"Nobody builds trading apps better than Trumpster 2000. Nobody."

## 🚀 Overview
Trumpster 2000 is a high-frequency market dominance dashboard designed with premium aesthetics and patriotic flair. This MVP (Phase 1) provides the core UI, the iconic "Building the Wall" loading sequence, and real-time signal visualization.

## 🛠 Tech Stack (Free Tier Optimized)
- **Frontend**: Vanilla HTML5, CSS3 (Glassmorphism), JavaScript (ES6)
- **Icons**: Lucide Icons (CDN)
- **Typography**: Google Fonts (Outfit & Orbitron)
- **Hosting**: Recommended: Vercel or Netlify (Free)
- **Backend (Phase 2)**: Supabase (Free Postgres & Real-time)

## 📁 Project Structure
- `index.html`: Main dashboard & SPA structure.
- `css/`:
    - `style.css`: Core design system & tokens.
    - `dashboard.css`: Premium component styling.
- `js/`:
    - `app.js`: Core interaction logic & wall building.
    - `signals.js`: Signal generation & visualization.
- `assets/`: 
    - `logo.png`: The iconic Eagle logo.
